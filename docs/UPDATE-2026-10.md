# Update: chemistry formatting, pictures, worksheet, several photos, install on phone

What is new
1. Formulas show properly (H2SO4 becomes H₂SO₄, Fe^{3+} becomes Fe³⁺, -> becomes →). Stored text is not changed.
2. Bengali letters use Noto Sans/Serif Bengali, so they look the same on every phone.
3. A question can have one picture (a structure, apparatus, graph). You crop it from a photo.
4. Print or save a worksheet as PDF, with an optional answer key (Admin > Print worksheet).
7. Choose up to 10 photos at once; they are read one after another into one review list.
8. Install the site on your phone like an app (menu > Install, or the browser's "Add to Home screen").
Also: drawn structures show in a fixed-width box so the lines stay lined up, and the AI now writes its explanation in the same language as the question.

How to update (about 10 minutes)
1. SQL: Supabase > SQL Editor > New query. Paste everything from `supabase/migrations/0007_pictures.sql`, press Run. ("Success" is the goal. Safe to run twice.)
2. GitHub: open the repository > Add file > Upload files. Drag in the contents of the update folder (keep the folder names: `web`, `supabase`, `docs`, `tests`). Do NOT upload `web/config.js` (it is not in the update). Commit. Cloudflare then publishes the site by itself.
3. Functions (for the AI prompt change): in PowerShell, in the project folder:
   `npx.cmd supabase functions deploy extract-question`
   `npx.cmd supabase functions deploy save-questions`
4. Open the site, refresh once. On a phone, close and reopen the tab if the old look stays.
